# Absolute Units Examples

The jobs contained in this folder demonstrate the use of absolute units in various contexts. These examples can serve as a reference for creating your own jobs that utilize absolute units.

## Artwork Files

### Absolute-Units.svg

- For use with all of the settings files in this folder.

## Settings Files

### Absolute-Units-Processes.json

- For use with the following machine types without modification: `pro24`, `pro32`, `pro36`, `pro48`, `ascent12`, `ascent24`, `ascent36`, `edge12`, `edge24`, `edge36`, `maker12`, `maker24`, `maker36`.
- Contains multiple processes. Some settings like `speed`, `power`, `frequency`, and `vector_sorting` will vary between processes.

### Absolute-Units-Processes-G100.json

- For use with the following machine types without modification: `g100_4x4`, `g100_6x6`.
- Contains multiple processes and hatch patterns. Some settings like `speed`, `power`, `frequency`, `pattern_type`, `passes`, and `vector_sorting` will vary between processes.

## Material Suggestion

These settings will mark on **anodized aluminum**.

_Note: Because some of the settings are modified to show how different parameters can be modified and because the PrintAPI does not have knowledge of the machine and laser, an optimal mark is not guaranteed._
