# Hatch-Only Examples

The jobs contained in this folder demonstrate the use of hatch processes. These examples can serve as a reference for creating your own jobs.

## Artwork Files

### Multi-Process-Hatch.svg

- For use with all of the `Multi-Process-Hatch-*.json` settings files in this folder.

### Single-Process-Hatch.svg

- For use with all of the `Single-Process-Hatch-*.json` settings files in this folder.

## Settings Files

### Multi-Process-Hatch-Processes-G100.json

- For use with the following machine types without modification (if they have a waveform fiber laser installed): `g100_4x4`, `g100_6x6`.
- Contains multiple processes and hatch patterns. Some settings like `speed`, `power`, `frequency`, `pattern_type`, and `passes` will vary between processes and patterns.

### Multi-Process-Hatch-G2.json

- For use with the following machine types without modification (if they have a waveform fiber laser installed): `g2`.
- Contains multiple processes and hatch patterns. Some settings like `speed`, `power`, `frequency`, `pattern_type`, and `passes` will vary between processes and patterns.

### Single-Process-Hatch-Processes-G100.json

- For use with the following machine types without modification (if they have a waveform fiber laser installed): `g100_4x4`, `g100_6x6`.
- Contains one process and some hatch patterns. Some settings like `speed`, `power`, `frequency`, `pattern_type`, and `passes` will vary between patterns.

### Single-Process-Hatch-G2.json

- For use with the following machine types without modification (if they have a waveform fiber laser installed): `g2`.
- Contains one process and some hatch patterns. Some settings like `speed`, `power`, `frequency`, `pattern_type`, and `passes` will vary between patterns.

## Material Suggestion

These settings will mark on **anodized aluminum**.

_Note: Because some of the settings are modified to show how different parameters can be modified and because the PrintAPI does not have knowledge of the machine and laser, an optimal mark is not guaranteed._
